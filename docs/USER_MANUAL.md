# 系统管理与操作基础用户手册

## 1. 系统概述
本系统是一个现代化的用户管理平台，提供用户信息的增删改查、角色分配、以及操作日志审计功能。系统均支持桌面端（Electron）和 Web 端访问。

## 2. 快速开始
### 2.1 登录系统
- **访问地址**: http://localhost:3288
- **默认管理员账号**: `admin` / `admin`
- **注意**: 首次登录后建议修改密码。

### 2.2 仪表盘
登录后主要展示系统概况：
- **统计卡片**: 显示总用户数、活跃用户数等关键指标。
- **图表分析**: 用户角色分布饼图、近期操作趋势图。

## 3. 功能操作指南

### 3.1 用户管理
位于左侧菜单 **"用户管理"**。

- **查看用户**: 支持分页浏览，可通过顶部搜索框按用户名筛选。
- **新增用户**: 点击右上角 **"新建用户"** 按钮，填写用户名、邮箱、密码并选择角色。
- **编辑用户**: 点击用户列表右侧的 **"编辑"** 按钮，可修改邮箱、角色或状态。
- **删除用户**: 点击 **"删除"** 按钮，确认后即可删除用户（管理员无法删除自己）。

### 3.2 角色与权限
目前系统内置三种角色：
1. **管理员 (Admin)**: 拥有所有权限，包括管理用户和查看日志。
2. **普通用户 (User)**: 仅能查看自己的信息（演示系统中暂未限制）。
3. **访客 (Guest)**: 只读权限。

### 3.3 操作日志
位于左侧菜单 **"操作日志"**。

- 系统自动记录所有关键操作（如登录、创建用户、删除用户）。
- 日志包含：操作人、动作类型、详细信息、IP 地址、操作时间。
- 支持按时间轴倒序查看。

## 4. 系统维护

### 4.1 数据备份
系统数据存储在 Docker Volume 或本地 SQLite 文件中。
- **Docker 模式**: 数据卷为 `2288_backend-data`。
- **本地模式**: 数据库文件位于 `backend/database/users.db`。
建议定期备份该文件。

### 4.2 常见问题排查
- **登录失败**: 检查网络连接，或确认后端服务是否启动 (端口 8288)。
- **页面白屏**: 尝试刷新页面（Ctrl+R / Cmd+R）。
- **无法连接服务器**: 确认 Docker 容器状态 `docker compose ps`。

## 5. 安全建议
- 生产环境务必修改默认 Admin 密码。
- 定期检查操作日志，关注异常登录尝试。
- 部署时请配置 HTTPS。
